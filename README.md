# A 股市场情绪指数（AFGI）—— 通达信数据版

基于 [Quantify-hp/Market-sentiment-index](https://github.com/Quantify-hp/Market-sentiment-index)
的九分项情绪指数模型，**把数据层从 Tushare / AkShare 换成通达信行情接口**，
不需要 Token、不需要积分、没有调用频次限制。

---

## 为什么要换数据源

原仓库的数据层依赖：

| 依赖 | 问题 |
| --- | --- |
| Tushare Pro | 需要 Token；ETF 日线（`fund_daily`）接口要求账户 **5000 积分**，否则波动率、风险偏好两个分项拿不到数据 |
| AkShare | 底层多为东方财富 / 新浪 HTTP 接口，在受限网络环境下会失效 |

本项目改为 **通达信公开行情服务器（TCP 协议）**，实测：

- 无需注册、无需 Token、无积分门槛；
- 可稳定返回全 A 个股日 K、指数日 K、ETF 日 K、申万行业指数日 K、除权除息记录；
- 8 台并发下载全 A（约 5200 只）日 K 约 4 分钟。

> 通达信服务器中只有部分站点开放历史日 K。`afgi/config.py` 里的 `TDX_HOSTS`
> 是实测可用的 `117.34.114.x` 站点；运行 `python run.py --probe` 可以重新探测。

## 安装与运行

```bash
pip install -r requirements.txt

python run.py --probe     # 可选：探测可用的通达信行情服务器
python run.py             # 全量构建，结果写入 output/
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `--offline` | 不联网，用本地缓存重算（秒级出报告） |
| `--refresh` | 忽略本地缓存，全量重建（约 4 分钟） |
| `--force` | 忽略并发锁强制运行 |
| `--history N` | 只保留最近 N 个交易日（默认全部） |
| `--bars N` | 每只标的缓存的日 K 根数，默认 800（约 3.2 年） |
| `--limit N` | 只取前 N 只股票，用于快速冒烟测试 |
| `--data-dir / --output-dir` | 指定缓存与输出目录 |

## 每日自动更新

`python run.py`（不带参数）就是日常更新命令：**只补齐缺失的交易日**，
再重算全部指标并刷新报告。已配置为每交易日 18:00 自动执行。

### 为什么不是全量重下

前复权因子以「窗口内最后一根 K 线」为基准递推，若只对新增片段单独复权再拼接，
基准不一致会造成价格跳变、涨跌停误判。因此缓存保存的是
**未复权原始 K 线 + 除权除息记录**，每次更新后用完整窗口**统一重算**前复权。

| 方式 | 网络量 | 耗时 |
| --- | --- | --- |
| 全量重下 | 每只 800 根 ≈ 420 万根 | 约 4 分钟 |
| 增量更新 | 每只约 10 根 ≈ 5 万根 | 约 40 秒（其余时间花在重拉除权记录与重算指标） |

实测：把缓存截断到 2026-09-22 后增量补齐到 09-30，重算出的 AFGI 与全量结果
**完全一致（38.83）**，验证了该做法的正确性。

### 更新流程

1. 用上证指数日 K 取交易日历，得到市场最新交易日；
2. 与缓存最后日期比对，算出需补下载的根数（缺失天数 + 5 根缓冲）；
3. 存量标的只下载增量并合并；
4. 重新拉取股票池，**新上市标的全量入库**，退市标的自动不参与最新一日计算；
5. 指数 / ETF / 行业指数直接拼接增量（指数不存在除权问题）；
6. 用合并后的完整窗口统一重算前复权，再跑一遍指标与打分。

### 定时任务与容错

- **非交易日**（如节假日）自动识别：市场最新交易日与缓存一致时不下载任何 K 线，
  直接跳过，不会写坏数据。
- **并发锁**：`data/.update.lock` 记录 PID，进程被强杀导致锁残留时会检测 PID
  存活状态自动清理；超过 3 小时无论如何强制清理；也可用 `--force` 忽略。
- **日志**：每次运行追加到 `data/update.log`。
- 缓存写入使用「临时文件 + 原子替换」，中途失败不会损坏已有缓存。

产出：

- `output/afgi_timeseries.csv` —— 完整时间序列（含九分项、原始指标、各分项状态）
- `output/afgi_latest.json` —— 最新交易日快照
- `output/report.html` —— 独立 HTML 报告（纯内联 SVG + 原生 JS，不依赖任何 CDN）
- `data/raw_frames.pkl` —— 原始行情缓存，二次运行秒级出结果

## 模型

### 九大分项与权重

| 分项 | 权重 | 主要输入 |
| --- | --- | --- |
| 波动率情绪 | 15% | 50ETF 20 日年化历史波动率（反向计分） |
| 成交情绪 | 15% | 全 A 成交额 / 20 日均值 |
| 股价强度情绪 | 10% | 全 A 创 252 日收盘新高股票占比 |
| 风险偏好情绪 | 10% | 沪深300 20 日收益 − 国债ETF 20 日收益 |
| 市场广度情绪 | 15% | 0.40×上涨占比 + 0.35×站上MA20占比 + 0.25×站上MA60占比 |
| 涨跌停情绪 | 15% | 0.40×涨停跌停比 + 0.30×炸板率(反向) + 0.30×昨日涨停今日收益 |
| 赚钱效应 | 10% | 0.60×近5日上涨占比 + 0.40×创60日新低占比(反向) |
| 板块扩散情绪 | 5% | 申万行业指数上涨占比 |
| 风格风险偏好 | 5% | 中证1000 相对沪深300 的 5 日强弱 |

权重与合成公式与原仓库 `enhanced_index.py` 完全一致。

### 打分方式

1. 每个原始指标换算成它在**自身过去 252 个交易日分布中的分位数**（0-100）；
2. 历史样本不足 60 日时取 50 分中性值；
3. 反向指标（波动率、炸板率、60 日新低占比）取 `100 − 分位数`；
4. 九分项按固定权重加权，总分裁剪到 0-100，映射为
   **极度恐惧 (<20) / 恐惧 (<40) / 中性 (<60) / 贪婪 (<80) / 极度贪婪 (≥80)**。

### 相对原仓库的两处改进

1. **前复权**：通达信日 K 是未复权价格，直接算 `close/prev_close` 会把
   10 送 10 之类的除权日表现为 −50%，被误判成跌停。本项目用通达信自己的
   除权除息记录（`category=1`）计算前复权因子，还原 OHLC 后再判断涨跌停。
2. **行业池补全**：通达信证券列表接口在 `881101-881146` 区段会返回失败，
   导致农林牧渔、基础化工、钢铁、有色金属、食品饮料等一级行业指数缺失。
   本项目改为按代码区间逐个探测有效性，把行业指数池补全到 368 个。

## 目录结构

```
afgi_tdx/
├── run.py                 # 命令行入口
├── afgi/
│   ├── config.py          # 服务器、权重、指标元信息
│   ├── tdx.py             # 通达信连接池（换站重试 + 并发）
│   ├── universe.py        # A 股股票池 + 申万行业指数池
│   ├── adjust.py          # 前复权
│   ├── indicators.py      # 10 个底层原始指标 + 4 个核心因子
│   ├── scoring.py         # 滚动分位数标准化、五档状态
│   ├── model.py           # 九分项合成 -> AFGI
│   ├── report.py          # HTML 报告（内联 SVG + 可缩放走势图）
│   └── pipeline.py        # 端到端编排
├── tests/
│   ├── test_afgi.py       # 模型单元测试（12 项）
│   └── chart_smoke.js     # 走势图交互离线冒烟（Node + DOM 桩）
├── data/                  # 行情缓存
└── output/                # CSV / JSON / HTML
```
